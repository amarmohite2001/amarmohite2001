# Architecture & Codebase

## Tech Stack

| Layer            | Technology                          |
| ----------------- | ------------------------------------ |
| Framework          | Next.js 15.3 (App Router), React 19 |
| Language           | TypeScript                          |
| Styling            | Plain CSS (`styles/globals.css`)    |
| Icons              | React Icons                         |
| Package manager    | npm (`package-lock.json`)           |

## Codebase Map

```text
app/
  layout.tsx               Root layout — theme init script, Header/Footer/GoToTop shell
  page.tsx                  Home route, composes components/sections/*
  blog/page.tsx              Blog index
  blog/[slug]/page.tsx        Individual blog post route
  resume/page.tsx             Resume route
components/
  Header.tsx, Footer.tsx, GoToTop.tsx    Shared shell components
  sections/                   Hero, About, Skills, Experience, Certifications,
                               Projects, Contact, Stats — one component per home section
context/
  ThemeContext                Light/dark theme provider (persisted via localStorage)
data/
  content.ts                  SINGLE SOURCE OF TRUTH for all site copy: bio, experience,
                               certifications, projects, blog posts, social links (505 lines)
lib/
  asset.ts                     Resolves static asset paths against NEXT_PUBLIC_BASE_PATH,
                                required because the site is served from a GitHub Pages subpath
public/
  images/                       Skill icons, project screenshots, certification badges
  resume/                       Resume PDF/DOCX/Markdown for download
styles/
  globals.css                   Global styles
docs/                          BUILD OUTPUT — generated by `npm run build`, do not hand-edit
                                or place documentation here (see project-docs/README.md)
```

**Legacy code note:** `Static_Code/` at the repo root is an older plain HTML/CSS/JS version
of this portfolio. It is not part of the active Next.js app, is not built or deployed by
the current toolchain, and should be treated as reference/archive only — not a place to
make changes intended for the live site.

## Content Model

All resume, experience, project, certification, and blog content lives in `data/content.ts`.
Update content there, not inline in components.

## Asset Handling

Any static asset referenced in a component or in `data/content.ts` must be resolved
through `lib/asset.ts`'s `asset()` helper (or already be an absolute URL), because the
production site is served from a subpath (`/amarmohite2001`) and plain root-relative paths
(`/images/...`) will 404 there.

## Development Workflow

```bash
npm install
npm run dev       # http://localhost:3000
npm run build     # rm -rf .next docs && next build → outputs to docs/
npm run preview   # npx serve docs — preview the static build locally
npm run start     # next start (standard Next.js server; not used in production)
```
